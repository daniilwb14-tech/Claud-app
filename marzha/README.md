# Маржа — юнит-экономика Ozon для Android

Приложение для продавцов Ozon: подключается к кабинету по ключу Seller API и показывает, сколько магазин
зарабатывает на самом деле — по каждому товару и по дням.

## Что умеет

| Экран | Что показывает |
|---|---|
| Сводка | Чистая прибыль, маржа, восемь плиток-показателей (каждая открывает свой раздел), график продаж по дням, неделям и месяцам, структура расходов |
| Товары | Прибыль и маржа по каждому артикулу, поиск, сортировки, убыточные товары, товары без себестоимости |
| Карточка товара | Экономика одной штуки: цена, все удержания и расходы на штуку, прибыль с штуки, остатки |
| Остатки | Склады Ozon, свой склад, поставки в пути, возвраты; деньги в товаре; на сколько дней хватит; сколько докупить |
| Проверка товара | Калькулятор юнит-экономики нового товара: цена, себестоимость, комиссия, логистика, выкуп, ДРР, налог; безубыточная цена, предельный ДРР, прибыль в месяц и сумма на первую партию. Цифры можно взять из своих продаж или из аналитики ниши Ozon (нужен Premium Pro) |
| Реклама и выплаты | Расходы на рекламу по товарам и кампаниям; из чего складывается сумма к выплате и как она набиралась по дням |
| Настройки | Цветовая гамма, налог, процент менеджера, свои расходы, выгрузка CSV, формулы всех показателей |

Есть демо-кабинет: приложение можно посмотреть без ключа.

Кабинетов может быть несколько: у каждого свои ключи Ozon, настройки, себестоимость, расходы и данные (свой файл базы и настроек). Переключение — по названию магазина на главной или в «Настройки → Кабинеты».

## Откуда данные

Только чтение, роль ключа «Admin read only».

| Данные | Метод Seller API |
|---|---|
| Начисления (выкупы, комиссия, логистика, реклама, хранение…) | `/v1/finance/accrual/by-day`, `/v1/finance/accrual/types` |
| Заказы и отмены | `/v3/posting/fbo/list`, `/v4/posting/fbs/list` |
| Товары | `/v3/product/list`, `/v3/product/info/list` |
| Остатки | `/v4/product/info/stocks`, `/v1/analytics/stocks` |
| Рекламные кампании (необязательно) | Performance API: `/api/client/statistics/daily/json` |

Старые методы `/v3/finance/transaction/list`, `/v2/posting/fbo/list` и `/v3/posting/fbs/list` Ozon отключил
осенью 2026 года, поэтому приложение работает на новых.

## Как считается прибыль

Чистая прибыль = выкуплено − возвраты − начисления Ozon − себестоимость проданного − налог − менеджер − свои расходы.

- Выкупы и удержания — по дате начисления Ozon, поэтому сумма сходится с разделом «Финансы → Начисления».
- Каждое начисление сверяется со своим итогом; несошедшийся остаток уходит в «прочие начисления».
- Начисления без привязки к товару и свои расходы делятся между товарами по доле выкупов.
- Налог можно считать со всех выкупов или только с оплаты покупателей (без баллов Ozon).

## Устройство

- `core` — чистый Kotlin без Android: клиент Ozon, разбор ответов, расчёт экономики. Тесты: `./gradlew -PcoreOnly :core:test`.
- `app` — Android (Jetpack Compose, Room). Ключ API шифруется ключом из Android Keystore и хранится только на устройстве.

## Сборка

`./gradlew :app:assembleDebug` — нужен Android SDK 35 и JDK 17. В CI сборку делает `.github/workflows/marzha.yml`
и кладёт APK в артефакты и в ссылку `refs/builds/marzha-apk`.

## Перед публикацией

1. Свой ключ подписи вместо `test.keystore`.
2. Проверка на нескольких реальных кабинетах: схема начислений Ozon новая, расхождения возможны.
3. Оплата подписки (RuStore или ЮKassa) и политика конфиденциальности.

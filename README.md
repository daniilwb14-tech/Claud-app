# Грош — учёт расходов для iOS

Приложение, которое записывает траты само: из Apple Pay, SMS банка, выписок и чеков — и отдельно показывает, сколько уходит на маркетплейсы.

## Что умеет

| Возможность | Как работает |
|---|---|
| Apple Pay / Wallet | Автоматизация «Команды → Wallet» вызывает действие «Записать трату» после каждой оплаты |
| SMS банка | Автоматизация «Команды → Сообщение» передаёт текст в действие «Разобрать сообщение банка» |
| Вставка текста | Скопированный SMS/пуш распознаётся: сумма, продавец, карта, категория |
| Импорт выписки (Pro) | CSV из Т-Банка, Альфы и любых банков; кодировки UTF-8 и Windows-1251; без дублей |
| Скан чека | QR-код кассового чека (ФНС) — сумма и дата читаются офлайн |
| Маркетплейсы (Pro) | Ozon, Wildberries, AliExpress, Яндекс Маркет, Мегамаркет, Lamoda: доля расходов, средний чек, динамика за полгода |
| Радар подписок (Pro) | Находит регулярные списания и считает их стоимость в месяц и в год |
| «Можно потратить сегодня» | Дневной лимит из бюджета месяца |
| Цена в часах работы | Сколько часов нужно отработать ради покупки |

Монетизация — StoreKit 2: подписка на месяц и год плюс разовая покупка «навсегда».

## Запуск

Нужен Mac с Xcode 16 или новее.

1. Откройте `Grosh.xcodeproj`.
2. В настройках таргета выберите свою команду (Signing & Capabilities) и поменяйте Bundle Identifier `app.grosh.ios` на свой.
3. Запустите на симуляторе или iPhone (iOS 17+). На первом экране можно загрузить демо-данные.

Покупки в симуляторе работают через `Products.storekit` (уже подключён к схеме). В Debug-сборке во вкладке «Ещё» есть переключатель «Pro без покупки».

Тесты ядра (парсеры SMS, выписок, чеков, подписок): `swift test`.

## Структура

- `Grosh/Core` — логика без UI: разбор сообщений банков, CSV, QR, классификация продавцов, поиск подписок.
- `Grosh/Models` — модель `Entry` (SwiftData).
- `Grosh/Services` — сохранение с дедупликацией, экспорт, покупки.
- `Grosh/Intents` — действия для «Команд» (App Intents).
- `Grosh/Views` — экраны на SwiftUI.

## Перед публикацией в App Store

1. Аккаунт Apple Developer, свой Bundle ID.
2. В App Store Connect создать продукты с идентификаторами `grosh.pro.monthly`, `grosh.pro.yearly` (одна группа подписок) и `grosh.pro.lifetime`.
3. Добавить политику конфиденциальности и условия использования (ссылки обязательны для приложений с подпиской).
4. Скриншоты, описание, возрастной рейтинг.
